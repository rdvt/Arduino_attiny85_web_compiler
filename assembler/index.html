TUTORIAL

Cómo usarlo, paso a paso

01 Escribe un programa mínimo

El ATtiny85 empieza a ejecutar en la dirección 0. Este programa configura el pin P0 como salida, lo enciende y se queda en un bucle:

.device attiny85
.equ DDRB = 0x17
.equ PORTB = 0x18

.org 0
rjmp reset

reset:
    ldi r16, 0x01
    out DDRB, r16
loop:
    out PORTB, r16
    rjmp loop

En la Digispark el bootloader micronucleus ya deja el puntero de pila listo, así que no hace falta inicializarlo. Si programas el micro sin bootloader, tendrás que configurar SPL antes de usar llamadas o interrupciones.

02 Entendé las direcciones

Las etiquetas y .org usan direcciones de bytes. Las instrucciones AVR ocupan 2 bytes, salvo JMP, CALL, LDS y STS, que ocupan 4. Los saltos relativos se calculan automáticamente.

Ejemplo: rjmp loop busca loop: en la segunda pasada y valida que entre en el rango de ±2048 palabras.

03 Usa directivas y datos

Se admiten .org, .byte/.db, .word/.dw, .dword/.long, .ascii, .asciz/.string, .fill, .align, .equ/.set y .def.

.equ VALUE = 0x1234
; También: .equ VALUE, 0x1234
.db 1, 2, 0xff, 'A'
.dw VALUE
.asciz "hola"
.fill 4, 1, 0xff

Las expresiones aceptan + - * / % << >> & | ^ ~, paréntesis y funciones low(), high(), byte1()…

04 Graba en la Digispark

Elige el objetivo Digispark para limitar a 6012 bytes. Descarga el HEX y abre el Flasher WebUSB. El flasher verificará el vector inicial y parcheará el salto del bootloader.

  1. Ensambla y revisa que no haya errores.
  2. Descarga el .hex.
  3. Pulsa Grabar en el flasher.
  4. Desconecta y conecta la placa con el selector abierto.
  5. Elige 16D0:0753 y no desconectes durante la escritura.
