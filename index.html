Antes de grabar WebUSB sólo funciona en Chrome o Edge de escritorio y con HTTPS o localhost. El bootloader micronucleus escucha unos segundos al conectar: pulsa Grabar primero y conecta la Digispark después. El botón queda bloqueado si el firmware supera 6012 bytes o no empieza con jmp/rjmp.

Tutorial rápido

Los tutoriales completos están dentro de cada herramienta y en el manual.

Ensamblar un LED

En el ensamblador, carga el ejemplo o escribe:

.device attiny85
.equ DDRB = 0x17
.equ PORTB = 0x18
.org 0
rjmp reset
reset:
  ldi r16, 1
  out DDRB, r16
loop:
  out PORTB, r16
  rjmp loop

Elige Digispark, pulsa Ensamblar y descarga el HEX.

Grabar el HEX
  1. Abre el Flasher WebUSB en Chrome o Edge.
  2. Elige el HEX descargado o el ejemplo publicado.
  3. Pulsa Grabar y conecta la placa cuando Chrome muestre el selector.
  4. Elige el dispositivo 16D0:0753.
Compilar C/C++ en el navegador
  1. Abre el editor C/C++: ya trae cargado el sketch de ejemplo.
  2. Edita el código o abre uno tuyo con Abrir local.
  3. Pulsa Compilar (o Ctrl/⌘ + Enter). La primera vez descarga el compilador, unos 20 MB; después queda en la caché del navegador.
  4. El panel derecho muestra la flash usada y los errores. Al terminar, pulsa Grabar compilado.
Si algo no funciona
  • No aparece la placa: pulsa Grabar primero y conecta la Digispark después, con el selector abierto. Tienes unos 5 segundos.
  • No puedo grabar: el firmware supera 6012 bytes o no empieza con jmp/rjmp. El panel de validación te dice cuál es el caso.
  • La compilación falla: revisa que no uses Serial (el ATtiny85 no tiene puerto serie) y que el sketch tenga setup() y loop().
  • Más dudas: el manual tiene una lista ampliada de problemas frecuentes.
