Integración

Del editor al chip, sin piezas sueltas

El compilador WebAssembly de esta página corre cc1plus, avr-as, avr-ld y avr-objcopy dentro del navegador. El agente local hace lo mismo con arduino-cli y el core digistump:avr de tu máquina. Las dos rutas producen el mismo Intel HEX, y ese HEX entra por WebUSB con el bootloader micronucleus.

Tutoriales de uso

          

            

              1 · Editar sin romper el sketch
              
    
                
  1. Abre DigisparkMouse.ino desde la lista del repositorio o carga un archivo local.
    2. 
                
  2. Modificá una línea; el resaltado, la numeración y el diagnóstico se actualizan solos.
    3. 
                
  3. Usa Tab para indentar y Ctrl/⌘ + S para guardar. El compilador guarda un backup .bak antes de escribir.
    4. 
                
  4. En un sketch DigiMouse aparecerá el panel de configuración: cambia valores, revisa la vista previa y pulsa Aplicar al código.
    5. 
              

            

            

              2 · Compilar y leer los errores
              
    
                
  1. Elige la variante de placa. Para este proyecto: digistump:avr:digispark-tiny.
    2. 
                
  2. Pulsa Compilar o usa Ctrl/⌘ + Enter. El compilador WebAssembly del navegador compila 100% en cliente: no se instala nada.
    3. 
                
  3. La barra muestra flash usada; el panel separa errores, warnings, tiempos y archivos incluidos.
    4. 
                
  4. Haz clic en un error para saltar a su línea. Un sketch que no compila nunca se habilita para grabar.
    5. 
              

            

            

              3 · Grabar de forma segura
              
    
                
  1. Compilá primero y confirmá que el vector de reset sea jmp/rjmp y que la imagen entre en 6012 bytes.
    2. 
                
  2. Pulsa Grabar compilado. Chrome abrirá el selector WebUSB.
    3. 
                
  3. Desconecta y vuelve a conectar la Digispark mientras el selector está abierto; elige 16D0:0753.
    4. 
                
  4. No desconectes la placa durante borrado o escritura. Al terminar se reenumera como mouse HID.
    5. 
              

              
Si aparece “La placa no volvió a responder después del borrado”: el borrado sí terminó. Dejá la placa desconectada, pulsá Grabar compilado inmediatamente y recién cuando Chrome esté esperando volvé a enchufarla. Ese segundo intento retoma la escritura y no vuelve a borrar la flash.

            

            

              4 · Si algo no funciona
              
    
                
  • Falta Arduino.h: la primera compilación no terminó de descargar el compilador. Vuelve a pulsar Compilar con conexión estable; después queda en la caché.
    • 
                
  • El programa no entra: el ATtiny85 tiene 6012 bytes útiles. La barra de flash se pone en rojo al pasarse.
    • 
                
  • La placa no volvió a responder después del borrado: no cierres ni recargues la página. Dejala desconectada, pulsá Grabar compilado inmediatamente y enchufala sólo cuando Chrome esté esperando. El siguiente intento retoma la escritura; no vuelve a borrar.
    • 
                
  • Errores raros con Serial: este micro no tiene puerto serie. Usa otro medio para depurar (por ejemplo DigiUSB).
    • 
                
  • No quiero usar el ratón USB: puedes editar y compilar cualquier sketch; el panel de configuración solo aparece con DigiMouse.h.
    • 
                
  • Puedes cargar un .hex/.bin ya compilado y grabarlo directamente, sin compilar nada.
    •

      Compilador WebAssembly
      
          
      
            Compilador ATtiny85 activo en el navegador: el editor usa el compilador WebAssembly (cc1plus 7.3.0 + binutils AVR) para producir el Intel HEX sin instalar ninguna herramienta.
          
      
          
      El HEX generado es idéntico byte a byte al de arduino-cli con digistump:avr:digispark-tiny para el core y las librerías que publica el sitio (DigiMouse, DigiUSB, DigiKeyboard, DigiJoystick, DigiCDC, Wire…). La compilación corre en un hilo aparte, así que puedes seguir usando el editor mientras trabaja y ver el progreso línea por línea. A partir de la segunda compilación tarda décimas de segundo.
      
        
      

        
      
          
      
            Ayuda y límites de la placa
            
        
              
      • ATtiny85: 8 KB de flash, de los que 6012 bytes son para tu programa (el resto es el bootloader), y 512 bytes de RAM.
        • 
              
      • Sin cristal: el reloj es RC calibrado a 16.5 MHz. F_CPU lo pone el core; no lo definas a mano.
        • 
              
      • Pines libres: P0 (PWM, SDA), P1 (PWM) y P2 (SCK). P3 y P4 son D± del USB bit-bang: no los uses. P5 es RESET: solo sirve como GPIO si grabas RSTDISBL y el bootloader micronucleus se pierde (la placa deja de ser grabable por USB).
        • 
              
      • El firmware debe arrancar con jmp/rjmp: micronucleus parchea el vector de reset. Se verifica antes de grabar.
        •                 
      • La compilación C/C++ corre en tu navegador con WebAssembly, en un hilo aparte: la primera vez descarga unos 20 MB y después funciona desde la caché.
